Project: Titanic Data Cleaning and Preliminary Analysis
Author: Shivam Nakoti

FILES
1. Shivam_Week1_Titanic_R_Data_Analysis.docx
2. titanic_week1_analysis.R
3. PNG charts used in the report

DATA SOURCE
https://github.com/datasciencedojo/datasets/blob/master/titanic.csv

HOW TO RUN
1. Open titanic_week1_analysis.R in RStudio.
2. Run the script from top to bottom.
3. It downloads the public Titanic CSV, cleans the data, creates normalized/encoded fields,
   performs descriptive/correlation analysis, and exports:
   - titanic_cleaned.csv
   - titanic_encoded.csv
